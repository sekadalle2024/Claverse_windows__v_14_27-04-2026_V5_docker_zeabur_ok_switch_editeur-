📋 RÉSUMÉ
─────────
L'endpoint API pour le calcul automatique des 33 notes annexes SYSCOHADA 
est maintenant opérationnel et intégré dans le backend Claraverse.

🎯 ENDPOINT PRINCIPAL
─────────────────────
POST /api/calculer_notes_annexes

📥 INPUT
────────
- Fichier Excel (.xlsx ou .xls)
- Format: multipart/form-data
- Paramètre: balance_file
- Contenu: 3 onglets (BALANCE N, N-1, N-2)

📤 OUTPUT
─────────
{
  "success": true,
  "notes_calculees": 33,
  "taux_coherence": 98.5,
  "duree_calcul": 12.5,
  "notes": {
    "Note_3A": { "colonnes": [...], "lignes": [...] },
    "Note_3B": { ... },
    ...
  },
  "statuts": { ... }
}
